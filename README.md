# CAPUZ NEGRO — The Codex

Starter visual do site narrativo de **Capuz Negro**, construído com Next.js App Router, React e GSAP/ScrollTrigger.

## Rodar localmente

Requer Node.js 20.9+.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
